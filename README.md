## 📖 About

Search is one of the most important yet overlooked components of any streaming platform.

As a user, I often found myself searching for movies on streaming services, changing keywords multiple times, and occasionally giving up when I couldn't find what I was looking for.

That experience made me curious.

**Why do two streaming platforms with millions of titles feel so different to search?**

Instead of simply asking *why*, I decided to approach it as a software engineering and machine learning problem.

This repository contains my independent engineering proposal for redesigning a modern streaming search system using techniques commonly used in large-scale search platforms.

The proposal is written in the style of an engineering design document and is intended for educational and technical discussion.

---

# 🎯 Objectives

The proposal explores how a traditional keyword-based search engine can evolve into a modern AI-powered search experience by combining:

- Query Understanding
- Autocomplete
- Fuzzy Search
- BM25 Lexical Retrieval
- Semantic Vector Search
- Hybrid Retrieval
- Reciprocal Rank Fusion (RRF)
- Learning-to-Rank (LambdaMART)
- Personalization
- Continuous Learning from User Behavior
